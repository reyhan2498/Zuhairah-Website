**Zuhairah** is a modern, full-stack e-commerce storefront engineered specifically for women’s modest activewear, workout tunics, and performance sports hijabs. Built on serverless, zero-upfront-cost infrastructure, it delivers a lightning-fast shopping experience optimized for performance, conversion, and global accessibility.

---

## ✨ Features

- **Performance-Driven UI:** Server-side rendered (SSR) catalog with dynamic filtering for size, coverage level, opacity rating, and breathability.
- **Variant Selector Engine:** Interactive selection for modest-specific product options (e.g., full chest coverage vs. neck tie-backs, 100% squat-proof ratings).
- **Seamless Cart & Checkout:** Lightweight client-side cart drawer paired with Stripe Hosted Checkout Server Actions.
- **Row-Level Security (RLS):** Production-grade Supabase database access control for public product reading and secure order creation.
- **Fully Responsive & Accessible:** Crafted with Tailwind CSS and `lucide-react` with mobile-first shopping navigation.
